# Как пушить версии по очереди

Каждая папка внутри `versions` является полноценной копией проекта без `.git`, `node_modules`, `build` и `dist`.

Порядок для 4 человек:

1. Первый человек копирует содержимое `versions/v1-lr14-docs` в корень репозитория, делает commit и push.
2. Второй человек делает pull, копирует содержимое `versions/v2-localization-roles` в корень репозитория, делает commit и push.
3. Третий человек делает pull, копирует содержимое `versions/v3-recommendations-reviews` в корень репозитория, делает commit и push.
4. Четвертый человек делает pull, копирует содержимое `versions/v4-tests-final` в корень репозитория, делает commit и push.

Копировать нужно именно содержимое версии, чтобы в корне репозитория снова лежали `client`, `server`, `docs`, `package-lock.json` и другие файлы проекта.

Не нужно пушить папки `versions/v1...` как вложенные папки проекта, если цель — показать последовательную историю разработки.
