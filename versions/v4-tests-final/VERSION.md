# Версия 4. Финал

Полноценная финальная копия проекта для четвертого пуша.

Что добавлено относительно версии 3:

- Backend: Jest, ts-jest, Supertest и API-тесты.
- Backend: unit-тесты рекомендаций.
- Frontend: тесты utility-функций и smoke test приложения.
- Docs: финальное деление на 4 версии и чеклист выполнения ЛР.

После пуша этой версии проект находится в финальном рабочем состоянии.
