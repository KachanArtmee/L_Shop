# Версия 2. Локализация и роли

Полноценная копия проекта для второго пуша.

Что добавлено относительно версии 1:

- Backend: `/locale`, session cookie для языка, роли `user/admin/manager`.
- Backend: admin API создания и редактирования товаров.
- Frontend: `LocaleProvider`, словари `ru/en`, плашка выбора языка.
- Frontend: admin-страница управления товарами.

Эта версия останавливается до отдельной реализации отзывов и рекомендаций.
