# Версия 1. ЛР14 Docs

Полноценная копия проекта для первого пуша.

Что добавлено относительно исходного проекта:

- Backend: Swagger/OpenAPI, `/api-docs`, отдельный `app.ts` для дальнейших тестов.
- Backend: typed JSON utility с JSDoc.
- Frontend: расширенные типы API, общий `AppButton`, utility-функции товара с JSDoc.
- Docs: чеклист выполнения лабораторных.

Эта версия не содержит функции ЛР15-16: локализацию, роли, рекомендации и отзывы.
